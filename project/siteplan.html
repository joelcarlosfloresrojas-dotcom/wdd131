Discovering Cusco

I choose this name because, and I think it triggers curiosity, and also it sounds like we are going to help them throughout the whole process

Site purpose

It provides information about Cusco, but mainly it organizes the trip for the user and everything they need.

Scenarios

  • How far in advance do I need to purchase tickets and train passes for Machu Picchu?
  • What are the best ways to acclimatize and prevent altitude sickness when I first arrive in the city?

Color Schema

  • #A63A28 (Dark Red): Used for headings.
  • #2E7D32 (Green): Used for accents and links.
  • #F9F6F0 (Cream): Used for the page background.
  • #333333 (Dark Gray): Used for paragraph text.
Typography
  • Merriweather: Used for all headings (h1, h2, h3).
  • Lato: Used for all body text, paragraphs, and lists.
